# 变更记录

版本与 npm 上的 `dsh-office-magic-box` 对应；日期为发布日（本地时间）。

## 1.4.0 — 2026-11-21

- **设置**新增「书签夹 → 清单文件」路径（默认 `$DSH_HOME/office-magic-box/bookmarks.json`）；换文件会重新加载清单，密码仍按书签 id 留在凭据库。
- 设置页改为四个分区：启动中控台 / 书签夹 / 发票合并 / 关于。
- 文档：新增 `docs/PROJECT.md`（结构、接口、数据、测试、发版）与 `docs/CHANGELOG.md`。

## 1.3.0 — 2026-11-21

- 新增第三个工具 **书签夹**：名称、网址、用户名、密码、打开方式（系统默认 / Chrome / Edge / Firefox / Brave / 自定义），点「打开」用指定浏览器进系统。
  - 密码存宿主凭据库（`ctx.credentials` 的 `api-key` 记录），清单文件里没有密码；界面不回显，只提供「复制密码」。
  - 浏览器探测与启动计划抽到 `lib/browsers.js`（纯函数，20 项测试）。
  - 浏览器用 detached 进程拉起，插件重载不会关掉用户浏览器。
- 主页改为三张功能卡；预览插画同步。
- Host 测试 87 项、渲染 54 项。

## 1.2.0 — 2026-11-21

- 发布准备：包名改为 `dsh-office-magic-box`（去 `private`），补作者、许可证、`engines.dsh`、仓库字段。
- 市场索引随包发布（`market/index.json` + `icon.svg`）；新增 `market/index-git.json`（git 源兜底）。
- 发版流水线 `dev/release.mjs`、发布后自检 `dev/verify-published.mjs`。
- 主页显示版本徽标；设置页新增「关于」（名称/版本/作者/许可证/插件目录 + 署名词）。
- 实时预览与打印：`officeKit`（PDFium）逐页渲染 → 界面预览；打印用隐藏 iframe + 系统打印对话框。

## 1.1.0 — 2026-11-20

- 新增第二个工具 **发票合并**：多张发票 PDF → 每张 A4 两面各两张，支持左右/上下、A4 纵横向、边距、中缝裁切线、单数页虚线位、自动版式。
- 主页入口 + 内部视图切换（主页 / 启动中控台 / 发票合并 / 设置）。
- 设置：中控台状态文件、发票默认打开与保存文件夹。
- 「从文件夹添加」「保存到文件夹」（Host 按路径读文件、落盘）。

## 1.0.0 — 2026-11-20

- 第一个工具 **启动中控台**：登记本机服务（名称/命令/工作目录），启动、重启、停止、查看输出；场景按顺序批量启动与整组停止。
- 数据落 `state.json`；插件安装为一枚左侧栏图标 + 主面板。
