# 办公魔盒

> 作者：**FBH · Forever Be Home**——「此心安处是吾乡」 · 版本见主页徽标（当前 1.2.0）· 许可证 MIT 

左侧栏的一个小面板，里面放日常办公的小工具。主页会显示当前版本号（如 `v1.2.0`），右上角「设置」可以改下面两个工具的路径。现在有两个工具：

- **启动中控台**：把盘里的服务、系统、脚本登记一次，之后点一下启动；多个服务可以编成场景，按顺序一键拉起。
- **发票合并**：多张发票 PDF 合并成一份「每张 A4 两面各两张」的文件，直接双面打印报销。

点左侧栏底部的「办公魔盒」图标进入主页，卡片点进去是各个工具，工具页左上角「← 办公魔盒」回主页。

## 安装

**方式一：插件市场（推荐）**

1. DSH → 插件 → 发现 → 添加索引：`https://cdn.jsdelivr.net/npm/dsh-office-magic-box/market/index.json`
2. 找到「办公魔盒」→ 安装
3. 重启 DSH（Host 半）或刷新页面（只改了界面时）

**方式二：本地目录**

插件 → 添加插件 → 选择本目录（开发调试用，改代码即时生效）。

**运行要求**

- DSH `>= 0.2.1-rc.2 || >= 0.2.2-rc.1`（见 `engines.dsh`），Node `^22.19.0 || >= 24.0.0`
- 依赖 `pdf-lib`（纯 JS，无原生模块），安装时随包解析
- 发票**实时预览**需要宿主自带的 `officeKit`（PDFium）；没有该组件的环境仍可合并、保存与下载，只是看不到预览

**安装前请知道**

- 启动中控台会以**你的用户身份**运行你登记的命令，等同于自己在终端里敲一遍
- 发票合并在本机完成，文件不上传；结果默认存到你设置的「保存文件夹」
- 两个工具都不联网、不包含遥测

## 启动中控台

1. 点「新增服务」，填名称、启动命令（整行，例如 `npm run dev`、`start.bat`、`python app.py`）、工作目录（可点「选择目录」）。需要浏览器打开的话再填「打开地址」。
2. 回到列表点「启动」，状态点变绿即为运行中；「输出」看这个进程最近的 stdout / stderr。改过命令的服务点「重启」才会用新命令。
3. 在「场景」栏点「新建场景」，把若干服务按顺序加成步骤，每步可设间隔（毫秒），步骤能上下调序，也可以勾「某步失败就停下」。之后点「一键启动」按顺序拉起；「停止这一组」停掉这个场景刚拉起的服务。

边界：

- 登记内容写在 `$DSH_HOME/office-magic-box/state.json`（缺省 `~/.dsh`），重启后仍在。
- 命令以你自己的身份执行，等同于在终端里手动敲一遍。
- 同一次只跑一个场景；「停止这一组」针对最近一次启动的那个场景。
- 退出 DSH 后，已经启动的进程不会被面板继续管理。

## 发票合并

1. 把发票 PDF 拖进虚线框，或点「选择文件」（可多选，最多 60 份、每份 25MB）；也可以点「从文件夹添加」，直接勾选设置里那个文件夹里的 PDF。列表里可以上移/下移（顺序就是打印顺序）和删除。
2. 选排版：**自动**（按发票长宽比判断：横版多就上下排，竖版多就左右排）、**左右两张**、**上下两张**；纸张 A4 纵向或横向；页边距毫米；要不要中缝裁切线。
3. **预览**：选好文件或改动上面任何设置后，预览区会在半秒左右自动重排，逐页显示真实排版效果（Host 用宿主自带的 PDFium 渲染，110dpi 给屏幕看）。
4. 点「**打印**」：调起系统打印对话框，在里面选打印机、双面（长边翻页）、份数即可直接打出来；打印用的是 190dpi 渲染，A4 逐页。
5. 想留一份文件有两个选择：「保存到文件夹」直接把 PDF 写进设置里的保存文件夹（会显示完整路径，同名自动加序号）；「下载」走浏览器的下载目录。

规则说明：

- 每张 A4 **一面排两张发票**，所以 K 张发票 = ⌈K/2⌉ 页 = ⌈K/2⌉ 张纸（双面）。
- 单页 PDF 与多页 PDF 都支持：多页 PDF 会按页拆成多张「发票」参与配对。
- 单数张时最后一页只有一张，空位会写一行小字提示，不会让你误以为漏打。
- 合并在本机完成（Host 半用 `pdf-lib` 排版、宿主 `officeKit` 的 PDFium 渲染预览），文件不上传。
- 预览依赖宿主自带的 PDF 渲染组件；如果当前环境没有（面板会写明「无法预览」），仍可用「生成打印文件」导出后用系统 PDF 阅读器打印。
- 「打印」走浏览器自带的打印对话框，所以双面、纸张、边距这些由打印机驱动决定；本插件只负责把每页排成正好一张 A4。

## 设置

主页右上角「设置」，三个路径都在本机、改完点「保存」立即生效：

| 设置项 | 作用 | 默认值 |
|:--|:--|:--|
| 启动中控台的配置文件 | 服务与场景存到哪个 `state.json`；**换文件前会先停掉当前运行的服务** | `$DSH_HOME/office-magic-box/state.json` |
| 发票默认打开文件夹 | 「从文件夹添加」从这里读 PDF | 系统「文档」文件夹 |
| 发票默认保存文件夹 | 「保存到文件夹」把生成的 PDF 放这里 | 系统「下载」文件夹 |

设置页底部还有一块「关于」：名称、版本、作者、许可证、插件目录。设置本身存在 `$DSH_HOME/office-magic-box/settings.json`；点「恢复默认」会清空三项并回到上面的默认目录。路径必须是绝对路径，发票文件夹必须已存在（保存文件夹会自动创建）。

## 面板之外的接口

Host 半在已认证的 `/api` 通道上暴露三个接口，面板用的就是它们：

- `GET /api/office-magic-box/state` → 服务、场景、运行状态、输出尾部、插件版本号。
- `GET|POST /api/office-magic-box/settings` → 读取 / 保存三个路径。
- `POST /api/office-magic-box/act` → 单个动作（`service.*` / `scene.*`）。
- `POST /api/office-magic-box/invoices` → 返回合并后的 PDF 字节，统计信息放在 `x-omb-stats` 响应头。
- `GET /api/office-magic-box/invoices/folder` → 列出文件夹里的 PDF（给「从文件夹添加」用）。
- `POST /api/office-magic-box/invoices/save` → 合并并写进保存文件夹，返回落盘路径。
- `POST /api/office-magic-box/preview` / `GET .../preview?token=&page=&dpi=` → 预览用的 token 与逐页 PNG。
